# # 如何运作 #

1. **Fork** 此寄存器(右上键)
2. 在叉中,编辑[`Contributors.md`](贡献者.md)并增加一行:
   ```markdown
   - [@your-username](https://github.com/your-username) — City, Country
   ```
3. 承诺** 新设一个分支机构的变动
4. 打开一个**推量请求** 返回此回转
5. 我们的机器人自动合并了 —— 欢迎登机!

#####规则

- 只有 `Contributors.md` 更改是自动合并的
- 每人一行——不要删除其他
- 保持干净和友好

##### 奖金

合并PR数到你的**Pull Shark**和**Open Sourcerer**的成就。 这是真正的自由进步。
